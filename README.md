# Mini-Hacks
Ein Team ist frühzeitig fertig mit seinem Hack? Hier gibts ein paar coole Mini-Hacks, welche sich schnell umzusetzen lassen.

* Heißer Draht: Unterhaltsames Geschicklichkeitsspiel (ohne Microcontroller und Programmierung realisierbar)
* Kompetitives Reaktionsspiel mit dem Calliope
* MakeYourCar: Kleine fahrbare Plattform in zwei Varianten (ohne oder mit Microcontroller)
* Die einfachsten Elektromotoren der Welt selbst bauen: [https://www.leifiphysik.de/elektrizitaetslehre/kraft-auf-stromleiter-e-motor/versuche/eigenbau-von-elektromotoren]
